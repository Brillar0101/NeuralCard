# v3.0.1-dev verification record

Run on 2026-10-07 against `hardware/NeuralCard.kicad_pcb` and
`hardware/NeuralCard.kicad_sch` using KiCad CLI. The switch mapping fix is
present in the schematic and board files.

## Switch nets

| Switch | Pads 1-2 | Pads 3-4 |
| --- | --- | --- |
| SW1 (BOOT) | IO0 | GND |
| SW2 (RESET) | GND | EN |

The switch datasheet groups contacts by physical row. Each row now stays on a
single net, avoiding the signal-to-ground short in v2.3.1 and v3.0.0-dev.
The KiCad schematic netlist and PCB footprint pads were inspected: SW1 pads 1-2
are IO0 and pads 3-4 GND; SW2 pads 1-2 are GND and pads 3-4 EN.

## KiCad results

- Filled GND zones on F.Cu and B.Cu; both zones were refilled before checking.
  Two B.Cu ground pads (R7.2 and U2.6) use direct zone connections because
  clearances left only one thermal spoke at each pad.
- PCB DRC with zone refill and schematic parity: 410 DRC violations, 191
  schematic-parity issues, and 0 unconnected items. The report has no
  `shorting_items` entries, but still contains two net-conflict findings and a
  crossing between EN and GND tracks, so this does not certify the board as
  short-free. The board is **not cleared for fabrication**.
- Schematic ERC: 0 errors and 42 warnings. These warnings report that the
  command-line environment did not load project-local `JLC`/`ST25DV` symbol
  and footprint libraries; this run does not establish a clean ERC result.
- Full reports: [`v3.0.1-dev-drc.rpt`](v3.0.1-dev-drc.rpt) and
  [`v3.0.1-dev-erc.rpt`](v3.0.1-dev-erc.rpt).

The pinout correction addresses the reported boot/reset short. Remaining DRC
and schematic-parity findings require separate cleanup before this revision is
released or submitted to a board manufacturer. The already released v2.3.1 tag
has not been modified.
